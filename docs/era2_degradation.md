# Era 2 降级策略

> A1 治理文档草稿，等待用户审核。所有降级路径必须保持 fail-closed，不得静默伪造缺失数据。

| 服务 | 降级条件 | 降级行为 | 用户可见提示 |
|---|---|---|---|
| Tavily 搜索 | 超预算 / 超时 / 被 policy 拒绝 | 跳过该步，带 `search_available=false` 继续 | 搜索不可用，基于本地数据 |
| 实时报价 | provider 返回空 / 超时 | 使用 T-1 收盘价并设置 `stale=true` | 报价为 T-1 收盘 |
| 商品价 | 正则提取失败 | 返回 `unavailable` 状态，不填价格 | 商品价暂不可用 |
| RAG | 知识库为空 / 服务异常 | 跳过 RAG 步骤 | 知识库暂无内容 |
| DeepSeek | 超时 / API 错误 | 返回空研报并附 `error_code` | 研报生成失败 |
| 收益区间引擎 | 历史数据缺口大于 30 天 | 收窄区间并添加 `data_gap` 标注 | 数据覆盖不足，区间仅供参考 |

# Era 2 降级策略

> A1 已获用户批准并正式生效。所有降级路径必须保持 fail-closed，不得静默伪造缺失数据。尚未进入对应开发阶段的服务仅锁定未来行为，不代表当前已经实现。

| 服务 | 降级条件 | 降级行为 | 用户可见提示 |
|---|---|---|---|
| Tavily 搜索 | timeout / 5xx / 域名校验失败 | 跳过搜索，标记联网数据不可用，仅使用本地证据 | 联网数据不可用，基于本地证据 |
| DeepSeek | 限流 / 超时 / 内容守门拒绝 | 降级到 AI-1 deterministic preview | AI 不可用，本地预览 |
| Alpha Vantage / FRED 实时报价 | 限速 / 数据缺失 | 使用已有 `market_history` 最近值并显示 stale 时间戳 | 报价数据已过期 |
| 经济日历 ingest | 公开页面格式变化 / ingest 失败 | 使用上次 ingest 缓存并标注过期天数 | 经济日历使用缓存 |
| Embedding | 模型加载失败 | 跳过向量召回，RAG 仅使用 BM25 | 向量检索不可用，仅关键词检索 |
| 多工具失败 | 单步工具失败 / 连续失败 | 单步失败不中断未来 agent loop；连续 3 步失败才终止 | 多项工具不可用，研究流程已降级或终止 |
